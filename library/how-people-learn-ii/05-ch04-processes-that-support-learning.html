第 4 章　支持學習的歷程

Processes That Support Learning｜pp. 69–83｜

臨床心語 整理｜更新於 2026-10-21

預估閱讀時間約 7 分鐘

學習目標

  1. 區分 metacognition、executive function 與 self-regulation。
  2. 說明記憶是「重建」，不是從檔案櫃取出複本。
  3. 說明提取線索（retrieval cues）如何影響一個人能回想什麼。
  4. 說明工作記憶、長期記憶，以及老化對記憶的影響。

摘要

學習需要統籌多種認知歷程。原書提出三種統籌方式：後設認知（監控與調節自己的認知）、執行功能（計畫、啟動、維持行為）、自我調節（以後設認知、策略行動與動機聚焦學習）。記憶是學習的基礎，但它不是檔案櫃：每次回憶都是依據過去經驗與當下線索的重建，所以記憶會隨時間改變。提取線索決定一個人能說出什麼；想不起來，不一定代表沒有知識。工作記憶與長期記憶的容量與表現，隨年齡改變；老年人常保留大意而失去細節。

關鍵洞見

  • 三種統籌方式：後設認知、執行功能、自我調節，彼此交織（p. 70）。
  • 執行功能的三項能力：在腦中維持資訊、抑制不當或過早的反應、維持或轉換注意（p. 70）。
  • 執行功能與學業：研究提示：它可能比一般智力更能預測入學準備度與學業成就（p. 71）。
  • 自我調節很難：自行調節學習並不容易，訓練有價值（p. 73）。
  • 記憶是重建：學習涉及依據過去經驗與當下線索重建記憶，不是重現複本（p. 74）。
  • 回憶隨時間改變：連情緒強烈的事件，細節也會遺忘、報告會改變（p. 76）。
  • 線索決定回憶：想不起來，不代表沒有知識；換線索會換出不同內容（p. 76–77）。
  • 工作記憶：容量低使兒童有學業進展不佳的風險（p. 77–78）。
  • 老化與記憶：情節記憶下降，但常保留大意；這種轉變不全是缺陷（p. 80–82）。

原文重點（中譯）

  • 後設認知是監控並調節自身認知歷程、並有意識地調節行為（含情感行為）的能力。 （p. 70）
  • 因此，記憶不是固定不變的，而是會隨時間變形，可能遺漏細節，也可能加入未曾發生的虛構細節。 （p. 76）
  • 因此，如果一個人在某個時刻想不起某項事實或技能，並不必然代表他沒有必要的知識。 （p. 76）
  • 第一，不應該對學習者知識與技能的任何單一評量給予過度的權重。 （p. 77）
  • 雖然這些年齡差異常被視為缺陷，但它們不一定導致衰退，甚至可能有用。 （p. 82）

精讀

這種「心智檔案櫃」的看法很有吸引力，但研究者已否定「知識（記憶）是儲存在心中的經驗複本」的想法。……儲存隱喻沒有捕捉到的事實是：學習其實涉及依據過去經驗與當下環境線索重建記憶的技能，而不是重現經驗的複本。……每個人都從主觀角度處理記憶，因此他對同一資訊或事件的記憶，不會與另一人的相同。 （pp. 74–75）

file cabinet view … compelling原書承認這個隱喻很直覺。解釋記憶時，先說明直覺為何吸引人，再說明它不準確。（本包教學建議）
reconstructing … cues in the present回憶 = 過去經驗 + 當下線索。來談者今天的敘述，反映的是今天的提取條件。
rather than reproducing copies不是複本。對來談者的敘述，不宜當作逐字記錄；也不宜因細節改變而判定不誠實。（本包詮釋）
subjective perspective … not identical同一事件，不同人記得不同；家人之間的說法有出入，是記憶的正常特徵。（本包詮釋）

實務推理框架

當對方「想不起來」或「做不出來」時，先分辨是知識不足，還是提取或統籌出了問題。（本包整理，非原書步驟）

  1. 確認統籌能力：對方能否設目標、選方法、追蹤進度？（p. 72）
  2. 換線索再問：改變提示、情境或視角，看能否回想更多（p. 76–77）。
  3. 不依賴單一評量；可用動態評量，讓嘗試之間有指導或回饋（p. 77）。
  4. 提醒對方連結強項情境，例如熟悉的活動或經驗（p. 77）。

記憶的文化差異：有跡象，但別過度概括

原書指出，有研究比較歐裔美國人、亞洲人與亞裔美國人對具體事件的詳細回憶，發現差異，並提出照顧者談論個人經驗的方式等假說；但這些研究「並未確立」差異，且要提防過度概括（p. 79）。臨床上，可先詢問來談者的家庭如何談論過去的事，不預設答案。（臨床詮釋，非原書結論）

限制：記憶研究多以大學生為樣本（p. 69，原書自述）。自主活動與執行功能的研究出自單一研究（p. 71–72）。9/11 記憶研究為單一研究（p. 76）。文化差異尚未確立（p. 79）。
